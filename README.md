#Wildhaven

Wildhaven is an exploration in AI-driven Game Development.  

The game itself is a 3D town-and-habitat-building strategy game for kids, in which the goal isn't building the biggest city — it's convincing wild animals to move in, because you've built somewhere they'd genuinely want to live.

Success is measured by whether both my kids (5 and 6) will want to play!


All assets are sourced from others, and this game wouldn't exist without them.  Quaternius, madtrollstudio, polypizza
